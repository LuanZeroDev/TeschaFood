# 06. Módulo "Mi Tienda" (Business Logic)

*Gestión para el perfil de vendedor.*

- [ ] **Pantalla de Onboarding para Negocios:** Vista persuasiva para que usuarios normales registren su comercio (si el flag de vendedor es falso).
- [ ] **Panel de Administración (Vendedor):**
    - [ ] CRUD de Productos: Formulario para añadir fotos, precios y descripciones.
    - [ ] Gestor de Pedidos Entrantes: Lista para aceptar o rechazar órdenes de compradores.
- [ ] **Dashboard de Ventas:** Visualización simple de ingresos acumulados en la billetera del negocio.
