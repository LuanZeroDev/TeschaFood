# 01. Infraestructura y Arquitectura Base

*Antes de crear pantallas, se debe establecer el "esqueleto" del proyecto.*

- [x] **Configuración del Theme Engine:** Implementar la paleta de colores del `DESIGN.md` (Primary Burgundy `#892138`, Metallic Gold `#D4AF37`) y el sistema de tipografía Inter.
- [x] **Estructura de Navegación:** Configurar el *Bottom Navigation View* con los 5 destinos: Inicio, Actividad, Billetera, Perfil y Mi Tienda.
- [x] **Implementación de Rejilla y Spacing:** Configurar las constantes de espaciado global basadas en la escala de 8px (xs: 4px, sm: 8px, md: 16px, etc.).
- [x] **Capa de Datos (Repository Pattern):** Definir interfaces para el manejo de productos, pedidos y usuarios.
- [x] **Inyección de Dependencias:** Configurar el contenedor para servicios de geolocalización y bases de datos.
- [x] **Setup de Google Maps SDK:** Configurar la API Key con permisos del Plan Pro y habilitar servicios de *Directions API* y *Distance Matrix*.
